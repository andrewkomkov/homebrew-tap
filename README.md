# Homebrew tap of andrewkomkov

This tap has the cask of [KeySwitch](https://github.com/andrewkomkov/key-switch), a keyboard
layout switcher for macOS.

```sh
brew install --cask andrewkomkov/tap/key-switch
```

To get a new version:

```sh
brew upgrade --cask key-switch
```

The release workflow of KeySwitch writes `Casks/key-switch.rb` after each release. Do not
change this file by hand.
